# Phân loại toàn bộ các dịch vụ có trên aws dựa trên chức năng kỹ thuật

AWS cung cấp hơn 200 dịch vụ đám mây, được phân loại chính thức theo chức năng kỹ thuật thành khoảng 25 danh mục lớn. Các danh mục này bao gồm từ cơ sở hạ tầng cốt lõi như tính toán và lưu trữ đến các lĩnh vực chuyên sâu như AI và IoT.

## Danh sách Phân loại Chính

Dưới đây là bảng tổng hợp toàn bộ các danh mục dịch vụ AWS dựa trên tài liệu chính thức, sắp xếp theo chức năng kỹ thuật.

| Danh mục (Tiếng Anh)               | Danh mục (Tiếng Việt)          | Mô tả ngắn gọn                                         |
| :--------------------------------- | :----------------------------- | :----------------------------------------------------- |
| Compute                            | Tính toán                      | Cung cấp sức mạnh xử lý cho ứng dụng, như EC2, Lambda. |
| Storage                            | Lưu trữ                        | Lưu trữ dữ liệu đáng tin cậy, như S3, EBS.             |
| Databases                          | Cơ sở dữ liệu                  | Quản lý dữ liệu quan hệ/NoSQL, như RDS, DynamoDB.      |
| Networking and content delivery    | Mạng và phân phối nội dung     | Xây dựng mạng VPC, CDN, như VPC, CloudFront.           |
| Analytics                          | Phân tích                      | Phân tích dữ liệu lớn, như Athena, Redshift.           |
| Machine Learning (ML) and AI       | Học máy và Trí tuệ nhân tạo    | Xây dựng mô hình AI/ML.                                |
| Management and governance          | Quản lý và quản trị            | Giám sát, tự động hóa, như CloudWatch, CloudFormation. |
| Security, identity, and compliance | Bảo mật, danh tính và tuân thủ | Bảo vệ dữ liệu, IAM, Shield.                           |
| Migration and transfer             | Di chuyển và truyền dữ liệu    | Chuyển workload lên cloud, như DMS, Snowball.          |
| Containers                         | Container                      | Quản lý container, như ECS, EKS.                       |
| Developer tools                    | Công cụ phát triển             | Hỗ trợ code, deploy.                                   |
| Application integration            | Tích hợp ứng dụng              | Kết nối dịch vụ, messaging.                            |
| Internet of Things (IoT)           | Internet vạn vật               | Quản lý thiết bị IoT.                                  |
| Media                              | Media                          | Xử lý video/audio.                                     |
| Front-end web and mobile           | Web và di động frontend        | Phát triển ứng dụng client.                            |
| End user computing                 | Điện toán người dùng cuối      | Desktop/virtual desktop.                               |
| Game tech                          | Công nghệ game                 | Dành cho game dev.                                     |
| Blockchain                         | Blockchain                     | Xây dựng ledger phân tán.                              |
| Business applications              | Ứng dụng kinh doanh            | ERP/CRM trên cloud.                                    |
| Cloud Financial Management         | Quản lý tài chính đám mây      | Theo dõi chi phí, budgets.                             |
| Customer enablement                | Hỗ trợ khách hàng              | Training, support tools.                               |
| Quantum technologies               | Công nghệ lượng tử             | Tính toán lượng tử.                                    |
| Satellite                          | Vệ tinh                        | Kết nối vệ tinh.                                       |
| Customer enablement                | Hỗ trợ khách hàng              | (Lặp, training/support).                               |
