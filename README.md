## 🎯 Topics Overview

### 1. System Design (Trọng tâm chính)

- Thiết kế hệ thống phân tán quy mô lớn
- High availability, scalability, fault tolerance
- CAP theorem, eventual consistency
- Microservices vs Monolith architecture
- Database sharding, replication, partitioning
- Caching strategies (Redis, Memcached)
- Message queues (Kafka, RabbitMQ)
- Load balancing, rate limiting, circuit breaker

### 2. Data Structures & Algorithms

- Complexity analysis (time/space)
- Trees, graphs, hash tables
- Dynamic programming
- Concurrency algorithms

### 3. Database

- SQL optimization, indexing strategies
- NoSQL (MongoDB, Cassandra, DynamoDB)
- ACID vs BASE
- Data modeling, normalization
- Transaction isolation levels
- [DBA role interview topics](./src/03-database-dba-role.md): backups/DR, HA, performance triage, security, upgrades, compliance

### 4. Infrastructure & DevOps

- Kubernetes, Docker
- CI/CD pipelines
- Cloud services (AWS/Azure/GCP)
- Monitoring, logging, observability
- Infrastructure as Code

### 5. Security

- Authentication/Authorization (OAuth, JWT)
- API security best practices
- OWASP vulnerabilities
- Encryption, data protection

### 6. Leadership & Soft Skills

- Technical decision making
- Mentoring junior developers
- Cross-team collaboration
- Trade-off analysis
- Project estimation và planning

### 7. Deep Technical Knowledge

- Concurrency, multithreading
- Memory management
- Network protocols (TCP/IP, HTTP/2, gRPC)
- Performance optimization
- Code review best practices

### 8. Code Review

- Code review goals and principles
- Comprehensive backend code review checklists
- Clean code, architecture, security, and performance considerations
- Best practices for review communication and collaboration

### 9. Computer Science Fundamentals

- Operating systems foundations
- Networking fundamentals
- Concurrency and synchronization
- Memory management and performance implications
- Compiler and runtime basics
- Distributed systems fundamentals
- Data modeling principles
- Complexity analysis and optimization thinking
- Testing fundamentals
- Git fundamentals and collaboration workflows

## 📖 How to Use

1. Start with the topics you're less confident about
2. Most files contain 10 detailed questions; Computer Science Fundamentals files contain 15 detailed questions each
3. Practice explaining concepts out loud as if in an interview
4. Focus on understanding trade-offs and real-world applications
